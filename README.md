## 📖 About The Project

**AI-Powered Smart Classroom** is an intelligent and modern educational platform designed to transform traditional classroom experiences through artificial intelligence and digital technologies.

The project focuses on creating a smarter, more interactive, and efficient learning environment by combining modern web technologies with AI-powered educational solutions.

### 🎯 Project Goals

- Enhance the modern learning experience.
- Introduce AI-powered educational solutions.
- Create an interactive digital classroom environment.
- Improve accessibility and learning efficiency.
- Explore the future of intelligent education.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone Repository

```bash
git clone https://github.com/sajjadul404/AI-Powered-Smart-Classroom.git
```

### 2. Navigate to Project

```bash
cd AI-Powered-Smart-Classroom
```

### 3. Install Dependencies

Make sure Bun is installed on your system.

```bash
bun install
```

### 4. Environment Variables

Create a `.env` file in the root directory.

Use `.env.example` as a reference:

```env
# Add your required environment variables here

API_KEY=your_api_key
```

> Configure the actual environment variables required by your application. Never commit private API keys or secrets to GitHub.

### 5. Run the Project

```bash
bun run dev
```

### 6. Open in Browser

```text
http://localhost:3000
```

> The development URL and port may vary depending on your project configuration.
